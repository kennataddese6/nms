Bubbly Day Nursery Website & Nursery
Management System Prompt
Project Overview
Create a modern, secure, mobile-responsive nursery website and integrated nursery management platform for Bubbly
Day Nursery.
The website should combine:
- Public nursery marketing website
- Parent communication portal
- Nursery management system
- Child learning journal system
- Staff management tools
- Finance and invoicing features
- EYFS tracking system
The system should function similarly to Famly and Tapestry.
